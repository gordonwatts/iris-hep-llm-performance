## Interpretation and joins

`identity` is verified only for the tested positive-control file. All other nominal requirements remain unverified; `emfrac-backup` is a separately labelled exploratory option with no nominal h conversion. Raw access succeeds for standard AnalysisJets, sampling energies, EM fraction and retained tracks/hit summaries. The exact QASTLE, request IDs, transformer images, types/counts/ranges and original code hashes are in the JSON.

Cross-probe comparisons check unique run/lb/event keys and native collection sizes on the same input file. They do not demonstrate a PHYSLITE/PHYS join. Any future cross-tier augmentation must establish common AOD parents, stream/skim coverage, unique event keys and overlap/missing-event counts, then object matching with angular/energy tolerances, ambiguity/unmatched rates and calibration mapping. Row position and DSID are insufficient.

The failed LC-topo transform does not prove absence. No PHYS/specialist transform was submitted because there is no demonstrated content gap yet. Current-main documentation motivates a thinning investigation but cannot replace the inaccessible exact-release job configuration. Independent trigger/closure, non-collision constraints, signal acceptance, kappa and numerical limits are unestablished. No h/n plane, tag/probe roles or region-A observation was computed.
