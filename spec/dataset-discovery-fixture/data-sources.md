# Run 3 CalRatio ABCD data-source contract

This contract adapts `calratio-abcd-spec.md` to Run 3 at a proposed 13.6 TeV. The user's explicit migration overrides the input's Run 1-only scope and modernization exclusion. The original specification is unchanged. This is a source and extraction implementation contract, not a measured Run 3 analysis: **no event field has been ServiceX-verified and no nominal tier is approved**. Input hash, requirement IDs, probes and observations are self-contained in `data-source-evidence.json`.

## Extraction layout and execution contract

Use release-matched `func_adl_servicex_xaodr25` queries and a flat final dictionary after a collection-gathering Select. Initial delivery is NFiles=1, no event limit unless backend-supported. Retain events before analysis cuts for the first controls. Later collision skims must retain all base jets and complete h/n fail regions; never impose probe pass, exactly two reconstructed jets, deltaPhi>2, or probe nonmatching. Maintain separate NCB skims without vertex/timing requirements. Confirm the *input derivation* has not already imposed these cuts.

Event keys are (run,event,LB) with BCID and stream/production provenance; deduplicate overlapping data streams. MC additionally needs DSID, campaign and simulation/production/file provenance: DSID+row number is never a join. Keep per-container indices and jagged offsets; every jet column must have the same length and ordering. Track and vertex arrays need explicit resolvable links and validity flags. Generic xAOD C++ signatures below are proposed accessor requirements, not guaranteed func_adl expressions: template arguments need the installed Python type-index accessor/helper syntax, enums and out-parameters need tested C++ wrappers, and nonstandard container names must be selected explicitly. `api-inspection` establishes API only, not storage.

Mixed-tier augmentation is **proposed, join unverified**. Require compatible parent reconstruction and event/stream coverage, uniqueness and overlap counts, duplicate policy, and matched/unmatched/ambiguous jet counts. Prefer original links if valid; otherwise document one-to-one angular and energy matching tolerances plus migration studies. PFlow and LC-topo jets cannot be joined by array position or assumed equivalent.

`preflight` records the exact locally constructed positive-control query and dependencies. It selects EventInfo('EventInfo') identity plus ordinary jet pT/eta/phi without cuts, in GeV/radians. Query construction succeeded; configuration resolution blocked delivery before submission. No output tree, event count, physics ranges or nonempty collection evidence exists. The local runnable probe is under probes/; the ledger embeds its essential imports/query so the deliverable stands alone.

For a real success record endpoint/backend release, DID/file GUID, request ID, cache status, versions, exact query, tree, entries, types, non-null/nonempty counts and finite/range/unit checks. Inspect materialized returned paths using uproot, including jet/track alignment and truth/trigger link validity. Isolate unusual attributes after the control; allow at most two informed query repairs. API, configuration, service and coverage failures are distinct from proven missing content. No direct input ROOT reads were used as extraction evidence.

## ABCD and normalization safeguards

A and its controls share the same common selection and tag/probe ranking. The tag is the highest-ET full candidate that matched a fired CalRatio object, not necessarily the leading reconstructed jet. Probe ranking is minimum good-track count, maximum defined h, maximum ET, then stable original index. Additional ordinary jets are retained, and the event full-candidate count must be <=2. A valid full-candidate probe therefore supplies the second candidate in A. The equivalence is a logical property of the proposed definitions; Run 3 physics equivalence is unmeasured.

Use qD=d, qB=rX*d, qC=rY*d, qA=kappa*rX*rY*d, with nonnegative parameters and lambdaR=mu*sR+qR+bR. Noncollision and additional non-QCD yields are separate per-region components. No control subtraction is forced negative; sparse controls remain Poisson. Auxiliary rectangles and single-jet studies constrain kappa only with justified extrapolation and event-overlap handling. Never tune to A, reuse the old P/Q correlation correction, or treat small linear correlation as tail closure. If control data cannot identify the transfer, no reliable limit follows.

Normalize using the complete signed preselection generator sumweights, not the returned one-file numerator. Resolve sample slicing/filters and generated branching fractions before multiplying sigma, filter efficiency and k-factor, and prevent double counting. Record negative weights and sumw2. The lifetime map must include region leakage and trigger/reconstruction/geometry/timing loss; do not apply a trigger efficiency twice. Recompute all region migrations under each validated detector variation, including role reassignment. Keep component correlations without adding a total systematic on top of its components. Preserve toy-based CLs and report Run 3 sigma×BR in pb; obtain an approved 13.6 TeV reference for the preserved 126 GeV benchmark before quoting normalized BR intervals.
